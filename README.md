# موقع ITS.ME — متجر السيتات

بدون مكتبات أو build — شغّل سيرفر بسيط وخلاص: `python3 -m http.server` ثم افتح `localhost:8000`
(أو ارفع الفولدر كله على Vercel / Netlify / أي استضافة static).

## الملفات
- `js/config.js` ← **كل حاجة بتعدّلها هنا**: النصوص، المنتجات، الأسعار، الشحن، الدفع، الأرقام.
- `js/config.ar.js` ← النسخة العربية (RTL). بتتحمّل تلقائي لما الزائر يضغط زرار **عربي / EN** (فوق في الهيدر)، والاختيار بيتحفظ. أي منتج جديد ضيف ترجمته في `PR` / `AR2` جوه الملف ده.
- `css/style.css` ← الألوان والخطوط · `js/app.js` ← محرك الأنيميشن والسلة.
- `assets/products/` ← صور السيتات (**PNG/WebP بخلفية شفافة**، `set-xxx.webp` قدام و`ضهر (اختياري)`) · `assets/products/thumbs/` ← صور السلة الصغيرة.

## حاجات متوقفة لحد ما تحدد
- **الاسترجاع/الاستبدال:** مخفي. فعّله بـ `store.returnDays: 14` (مثلاً).
- **جدول المقاسات:** فاضي لحد ما تبعت القياسات الحقيقية (فيه قالب جاهز في `sizeCharts` جوه config.js).
- **Mega Deal** (خصم على القطعة التانية/التالتة): مقفول. فعّله بـ `store.smartSale.enabled: true`.
- **New Drop:** ظاهر "Coming soon". حط `date` فيه عدّاد، أو `enabled: false` لإخفائه.

## تعديلات النسخة v6
- **كل لون = كارت لوحده:** اكتب المنتج في `config.js` بألوانه (`colors: [...]`) والسطور اللي في آخر الملف بتفصل كل لون تلقائي (اسم المنتج + اللون).
- **زرار اللغة:** عربي / English — بيعمل reload ويحمّل `config.ar.js`.
- **ضهر الزيب أب الخمري (Gothic)** وضهر **هودي Spider** اتضافوا (`*-back.webp`).
- صور السيتات: `assets/products/set-xxx.webp` (قدام) و`set-xxx-back.webp` (ضهر) و`thumbs/set-xxx.webp`. استبدلها بصور من غير موديل بنفس الأسماء وهتشتغل مباشرة.
